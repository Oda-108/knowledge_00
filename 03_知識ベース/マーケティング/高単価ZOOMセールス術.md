# 高単価ZOOMセールス術

購入コンテンツから抽出した高単価商品（30万円以上）のZOOMセールスノウハウ。

---

## ZOOMセールス10の極意

### 全体の流れ

```
1. ラポール形成
2. 現状のヒアリング
3. 理想の未来を描かせる
4. 具体的なステップを提示
5. 一人では難しいと認識させる
6. 商品説明
7. 価格提示
8. クロージング
9. 反論処理
10. 決済・契約
```

---

## 極意① ラポール形成

### なぜ重要か

> 「何か売りつけられるのか？」という警戒心を短時間で解くことがポイント

ラポール形成をおこたると、クロージング段階で断られやすくなる。

### 4つのポイント

#### 1. こちらがお客様に緊張感を持たない
- 緊張が伝わるとお客様も緊張
- リラックスした表情を心がける
- 鏡の前で練習、相槌のレパートリーを書き出す

#### 2. お客様を笑顔にする
- あなた自身が笑顔になる
- 「敵意がない」ことを伝える
- 明るく自然体に接する

#### 3. お客様を肯定する
- 全力でいい部分を見つけ肯定する
- 自己肯定感が低い人が相談に来る
- 自己肯定感をマックスまで上げる

**具体的な褒め方:**
```
「今日はようこそ、お会いできて光栄です。」
→「ちょっといいですか？」
→「声めちゃくちゃかっこいいって言われたことありませんか？」
```

**謙遜された場合:**
```
「絶対そんなことないですよ！
 少なくとも僕は声を聞いて癒されてます、ありがとうございます。」
```

→「少なくとも私はそう思う」と事実として伝える

#### 4. お客様より少し優位に立つ

> 「偉そうな態度」ではない

セールス前に伝える:
```
「なるべく時間を有意義なものにしたいと思ってます。」
```

---

## 極意② 現状のヒアリング

お客様の現状を把握する:
- 今どんな状況か
- 何に困っているか
- これまで何を試したか

---

## 極意③ 理想の未来を描かせる

お客様が本当に望む未来を明確にする:
- 具体的な数字で
- 感情レベルで
- 生活レベルで

---

## 極意④ 具体的なステップを提示

### なぜ重要か

> 人は未知の領域に対し恐怖や不安を感じる

「私にもできそう」と思わせることが重要。

### 具体例（稼ぐ系）

```
「私はまず月100万稼ぎました。」
↓
「次に月100万稼ぎたい人たちに『こんな風に稼ぎました。
 その方法を全力で教えるので、成果が出たらお金をください』と伝えます。」
↓
「月100万稼ぐ人に20%の20万をもらい、
 そういう人が10人できるだけで月200万いきます。」
↓
「月200万稼いだとき、労働ってしてますか？してませんよね。
 そうすると好きな時にハワイに行けます。」
↓
「まずうちの商品を使って全力で100万稼ぎに行きましょう。
 そのためのバックアップをさせていただきます。」
```

### 具体例（非稼ぐ系・恋愛系）

```
①ファッション、ダイエット、髪型、身なりを整える
②女性と話す
③女性と話せるようになったらマッチングアプリ、街コン、合コンに行く
```

### 山登りの例え

> 富士山の頂上が理想の未来
> そこへ行くためにどのルートをどの工程で通るか説明する

- 過去に登った経験がある人→不安を感じない
- 一度も登ったことがない人→不安を感じる

**不安を取り除くことが重要**

## 極意⑤ 一人では難しいと認識させる

### なぜ必要か

> 「自分1人でできそうだな」となると、商品への興味がなくなる

④で希望を見せた後、⑤で冷静になってもらう。

### 具体的なトーク

```
「月100万稼ぎたいと言ってたけど、自分1人でできそうですか？」
```

```
「ダイエットも1人で頑張ろうとしても、
 お菓子や美味しいものの欲求に負けてしまうから、
 ジムに通ったりパーソナルトレーニングを契約したりしますよね」
↓
「自分1人の力で継続できるのは、100人いたらたったの5人くらいです」
↓
「誘惑に負けないためには、いい環境に身を置くのが何より大事」
```

## 極意⑥〜⑩ 商品説明〜決済

### ⑥ 商品説明
- 商品の内容を説明
- お客様の問題をどう解決するか

### ⑦ 価格提示
- 価値を十分に伝えてから
- 投資対効果を示す

### ⑧ クロージング
- 「やりますか？」とシンプルに聞く
- 沈黙を恐れない

### ⑨ 反論処理
- よくある反論に備えておく
- 「お金がない」「時間がない」「相談したい」

### ⑩ 決済・契約
- すぐに決済できる導線を用意
- 分割払いのオプション

---

## 核心まとめ

### セールス成功の方程式

```
ラポール形成 × 自己肯定感アップ × 具体的ステップ × 環境の重要性 = 成約
```

### 最重要ポイント

1. **自己肯定感をマックスに**
   - 不安な状態では人は行動できない
   - まず自己肯定感を上げる

2. **具体的なステップを見せる**
   - 未知への恐怖を取り除く
   - 「私にもできそう」と思わせる

3. **環境の重要性を伝える**
   - 一人では続かない
   - 環境があれば成功できる
