# 6教育フレームワーク

購入コンテンツから抽出した「教育」の具体的なフレームワーク。
コンテンツ販売・X運用における最重要概念。

---

## 基本構造

### 従来の誤解
```
集客 → 教育 → 販売
```

### 正しい構造
```
集客 → 教育 → 教育 → 教育 → 教育 → 販売
```

**ポイント**: 教育が1回で終わると思っている人が大半。実際は複数回の教育が必要。

---

## 6つの教育要素

### 1. 目的の教育
**「なぜこれをやるべきなのか」を理解させる**

- 問題を放置するとどうなるか（恐怖）
- 今行動することのメリット（希望）
- 目的意識を明確化させる

例文パターン:
- 「このまま放置すると3年後には...」
- 「今始めれば1年後にはこうなれる」

---

### 2. 信念の教育
**「これが正しい方法だ」と信じさせる**

- 他の選択肢を排除する
- これしかないと思わせる
- 迷いを消す

例文パターン:
- 「FXより情報発信が優れている理由は...」
- 「他の方法は遠回り。これが最短ルート」

---

### 3. 手段の教育
**「この方法で実現できる」と理解させる**

- 具体的なステップを示す
- 再現性があることを証明する
- 「自分にもできそう」と思わせる

例文パターン:
- 「ステップ1、ステップ2、ステップ3で完了」
- 「初心者でも30日で結果が出た実例」

---

### 4. 投資の教育
**「お金を払う価値がある」と納得させる**

- 知識への投資が最強であることを刷り込む
- 投資対効果を示す
- 無料では得られない価値を伝える

例文パターン:
- 「ダメダメだった自分→知識を身につける→成功した」
- 「この投資が100倍になって返ってきた」

---

### 5. 行動の教育
**「今すぐ行動すべき」と決断させる**

- 緊急性を作る
- 機会損失を意識させる
- 背中を押す

例文パターン:
- 「今日決断しないと、また同じ1年を過ごす」
- 「この機会を逃したら、次はない」

---

### 6. 信頼の教育
**「この人から買いたい」と思わせる**

- 自分の実績・ストーリーを語る
- 失敗談を含めてリアルに
- 共感と信頼を構築

例文パターン:
- 「俺も昔は同じ失敗をした」
- 「だからこそ、お前の気持ちが分かる」

---

## 教育の実践方法

### 日々の発信で使う

各投稿で1つ以上の教育要素を含める:

| 曜日 | 教育要素 | 投稿例 |
|------|---------|--------|
| 月 | 目的 | 「このまま放置すると...」 |
| 火 | 信念 | 「他の方法は遠回り」 |
| 水 | 手段 | 「具体的なステップ」 |
| 木 | 投資 | 「知識投資で人生変わった」 |
| 金 | 行動 | 「今日決断しないと...」 |
| 土 | 信頼 | 「俺の失敗談」 |
| 日 | まとめ | 価値提供投稿 |

### ローンチ時に使う

ローンチ前2週間で全6要素を網羅:

```
Day 1-3: 目的の教育（問題提起）
Day 4-6: 信念の教育（選択肢を狭める）
Day 7-9: 手段の教育（解決策を示す）
Day 10-11: 投資の教育（価値を伝える）
Day 12-13: 信頼の教育（ストーリー）
Day 14: 行動の教育（ローンチ当日）
```

---

## よくある失敗パターン

### 1. 教育なしで販売
```
集客 → 即販売
```
→ 「買う理由」がないので売れない

### 2. 教育が1回だけ
```
集客 → 教育(1回) → 販売
```
→ 教育が浅く、信頼構築不足

### 3. 同じ教育の繰り返し
```
集客 → 信念の教育 → 信念の教育 → 信念の教育 → 販売
```
→ 他の要素が欠けていて決断に至らない
