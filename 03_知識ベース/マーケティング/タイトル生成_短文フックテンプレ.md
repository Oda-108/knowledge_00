# タイトル生成_短文フックテンプレ

ペルソナ別キーワード辞書から、短文フック（タイトル候補）を量産するためのテンプレ。

## 1. 使い方
1. ペルソナを決める
2. 「目的/痛み/欲望/恐れ/証拠/行動/トリガー/CTA/情景」からキーワードを選ぶ
3. 下記の型に流し込む
4. 10〜30本出す

## 2. 型（短文フック）
- まだ[痛み]で消耗してるのか
- [トリガー]がないと終わる
- [目的]は、[行動]でしか取れない
- [恐れ]を消すなら、[証拠]
- [欲望]は[仕組み]で作る
- [情景]のままでいいのか
- [行動]しない限り、[目的]は遠い
- [トリガー]を知らないと損する
- [欲望]を叶える最短ルート
- [証拠]があるから勝てる

## 3. 置換メモ
- [仕組み]は「仕組み/自動化/導線/ルール/テンプレ」などに置換
- NGワードに当たる表現は除外

## 4. 出力フォーマット
```text
Persona: [ペルソナ名]
Goal: [目的]

Hooks
1. ...
2. ...
3. ...
```
