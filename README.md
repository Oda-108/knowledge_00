## 🔍 知識ベースの使い方

### AIアシスタントへの指示
AIに質問する前に、関連する知識ベースを参照させることで回答精度が大幅に向上する。

```
例: 「6教育フレームワークを参照して、来週の教育投稿を作成して」
例: 「武器商人戦略マニフェストのペルソナを踏まえて、LP構成を考えて」
例: 「ペルソナ別キーワード辞書を使って、タイトル候補を10本出して」
```

### 知識の更新サイクル
- 新しいノウハウを得たら → 既存ファイルに追記 or 新規ファイル作成
- 古くなった情報 → 更新日を付けて修正
- 関連性のある知識同士 → ファイル間リンクで接続

### ファイル命名規則
- カテゴリを接頭辞にする（例: `X運用〜`, `ローンチ〜`）
- 内容が一目で分かる日本語タイトル
- 追加日を持つ場合はファイル内にメモとして記載
